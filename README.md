# DormHelper
DormHelper — проектирование информационной системы для общежития

## О проекте

DormHelper — проект цифрового сервиса для централизованного решения бытовых и организационных вопросов студентов, проживающих в общежитии.

Цель проекта — структурировать взаимодействие студентов с администрацией и спроектировать единую систему для работы с обращениями, объявлениями и справочной информацией.

## Мой вклад

В рамках проекта я занимался аналитической частью:

- Анализировал предметную область, потребности пользователей и существующие решения.
- Формулировал функциональные требования к системе.
- Определял роли пользователей и описывал сценарии взаимодействия с приложением.
- Моделировал бизнес-процессы с использованием UML Use Case, IDEF0, IDEF3 и ARIS EPC.
- Разрабатывал функциональную структуру системы и концепцию учёта и отчётности.

## Материалы проекта

- **Аналитическое портфолио** — основные результаты и модели проекта.
- **Проектный отчёт** — подробное описание предметной области, функциональности и бизнес-процессов.

## Технологический контекст

- Для проекта предусмотрен настольный прототип на Python с использованием PyQt6 и SQLite. Аналитическая документация описывает проектируемую систему и функциональные сценарии.
